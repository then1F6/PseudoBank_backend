# README

### Description
  MBank. Бэкенд проект псевдо банка.

### Features
- регистрация через @gmail.com почту OAuth
- переводы денег между счетами 
- у каждого свой профиль который можно менять и настраивать
- система аватарок и их обновлений
- возможность отравлять запросы денег
- просмотр своих запросв денег и запросв к себе 
- просмотр своей истории транзакций
- поиск по username; поиск по display name
- разделение ролей user admin и owner
- доступ к большей информации для admin
- возможность нзанчать и снимать роли админос с пользователй для owner
- возможность подмены дейсвтий пользователя для owner


### Stack 
  Проект написанн на TS. Рантайм предпочтительно bun. Http фраеморк - Hono.
  Валидация днных через Zod. БД PostgreSQL. Запросы отпарвялют через pg.
  Используется квери билдер для запросов Kysely. JWT через jose

  TS Bun Hono PostreSQL Kysely
